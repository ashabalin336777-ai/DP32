## 1. Тема и зачем это нужно

**Просто.** Инженеру нужно быстро понять: какой микроконтроллер выбрать, где он дешевле и есть ли он на складе у трёх крупных поставщиков. Сейчас это ручной труд: открыть ЧипДип, Платан, Промэлектронику, списать цены и сравнить таблицы.

**Технически.** Предметная область — 32-битные MCU. Источники — HTML-каталоги конкурентов плюс эталонный каталог своей продукции (OUR). Результат — снимок рынка в SQLite, витрина сравнения и валидированный PDF-отчёт.

---

## 2. Цель работы

**Просто.** Собрать рабочий прототип, который сам подтягивает прайсы, считает разницу в цифрах и пишет понятный отчёт. Нейросеть помогает читать страницы и формулировать выводы, но **не придумывает цены**.

**Технически.** MVP системы конкурентного анализа: ingest листингов и карточек → типизированное извлечение спецификаций → детерминированные дельты и KNN-подбор аналогов → LLM-черновик отчёта с FactValidator (`VALID` / `INVALID`) → публикация демо на Timeweb VPS.

---

## 3. Задача

**Просто.**

- Сходить на три стока и собрать артикулы, цены и остатки.
- Дать страницу «выбери МК по параметрам».
- По одному артикулу показать, кто дешевле и у кого больше на складе.
- Найти похожие корпуса/ядра для своей линейки.
- Сложить это в PDF, который человек ещё раз просматривает.

**Технически.**

- HTTP-скрейп листингов (`httpx`) и обход JS-карточек (`Playwright`).
- Селекторы + LLM-агент 1 (`instructor` + Pydantic `MCUExtractSpec`).
- Параметрический finder, матрица `цена / наличие`, scatter Chart.js.
- Pin-compatible фильтр + `StandardScaler` + `NearestNeighbors(k=5)`.
- Агент 2 + детерминированная сверка `cited_facts` со строками Pandas.
- Docker Compose, HTTPS через существующий nginx SHA Studio.

## 4. Стек технологий

Читать слева направо: сначала «что это в быту», затем официальное имя.

| Простыми словами | Технический термин |
|---|---|
| Язык, на котором написан весь проект | **Python 3.11+** |
| «Excel внутри программы»: таблицы, проценты, кто дешевле | **Pandas** |
| Поиск похожих МК по Flash, RAM, частоте, числу выводов | **scikit-learn**: `StandardScaler`, `NearestNeighbors` (k=5) |
| База в одном файле на диске, без отдельного сервера БД | **SQLite** (режим **WAL**, модуль `sqlite3`, без ORM / SQLAlchemy) |
| Быстро скачать обычные страницы каталога | **httpx** + **BeautifulSoup** (CSS-селекторы) |
| Открыть карточку товара как в настоящем браузере | **Playwright** (Chromium) |
| Нейросеть достаёт поля из HTML в строгий бланк | **Neural Deep Pro**, модель **Qwen2.5-14B-Instruct**, библиотека **instructor** + **Pydantic** |
| Нейросеть пишет текст отчёта, числа берёт из таблицы | **Qwen2.5-32B-Instruct** + **FactValidator** (`VALID` / `INVALID`) |
| Поиск ссылок на карточки по артикулу | Neural Deep **`search:web`** |
| Шаблоны сайта и PDF | **Jinja2**, PDF — **WeasyPrint** (на Windows запасной путь через Playwright) |
| Точки на графике «наличие × цена» | **Chart.js** (только рисует, расчёт радиуса — Pandas) |
| Сайт без тяжёлого веб-фреймворка | стандартный **`http.server`** + Jinja2 (`src/web.py`) |
| Упаковка «запустил — работает на сервере» | **Docker**, **docker-compose**, хостинг **Timeweb VPS** (2 vCPU / 4 GB) |
| Публичный адрес с замком HTTPS | **nginx** SHA Studio, домен **dp32.shastudio.ru** |
| Секреты не вшиты в код | **python-dotenv**, файл `.env` |
| Повторно не гонять одну и ту же страницу в нейросеть | **diskcache** |
| Автопроверка, что модули не сломались | **pytest** |
| Ночной запуск сбора данных | **cron** (или **APScheduler** в контейнере) |

Принцип диплома: **цифры считает программа, нейросеть пишет слова**.

## 5. Как устроена система

**Просто.** Есть конвейер «собрал → сохранил → сравнил → напечатал отчёт» и отдельно витрина в браузере. Витрина читает последнюю сохранённую картину рынка и не пересчитывает проценты в JavaScript.

**Технически.** Два контура:

1. **Batch-пайплайн** `src/pipeline.py`: fast catalog → `search:web` → Playwright карточки → extract → SQLite snapshot → matcher → analyzer → `reports/analysis_YYYY-MM-DD.pdf`.
2. **Демо** `src/web.py`: маршруты `/finder`, `/compare`, `/charts`, `/reports`. Источник цифр — `load_latest_snapshot()`; если снимок пуст, подставляются HTML-фикстуры.

Данные лежат в `data/mcu_competitors.db` (в git не входит). Семена листингов — `data/catalog_seeds.json`, селекторы — `data/extract_selectors.json`.

## 6. Возможности

Каждый пункт: сначала для комиссии без IT-бэкграунда, затем формулировка для техраздела.

### 6.1. Подбор микроконтроллера

**Просто.** На сайте задаёте бренд, ядро, объём памяти, корпус — таблица оставляет подходящие артикулы. Большой список не вываливается целиком: по 50 строк на страницу.

**Технически.** `/finder` — фасеты и диапазоны (`brand`, `core_arch`, `flash_kb`, `freq_mhz`, `package`, `temp_range`), дедуп по MPN (`merge_unique_parts`), пагинация `FINDER_PAGE_SIZE=50`.

### 6.2. Сравнение цены и наличия

**Просто.** Вводите один артикул (или номер карточки) — видно цену и склад ЧипДип, Платан и Промэлектроники: кто дешевле и у кого больше штук.

**Технически.** `/compare?part=` строит матрицу Pandas: Δ цены к минимуму, Δ наличия к максимуму. Резолв MPN / nomenclature id / URL — `src/catalog.py`.

### 6.3. Карта рынка

**Просто.** Пузырьковый график: вправо — больше на складе, вверх — дороже, размер пузыря — объём остатка.

**Технически.** Chart.js bubble; payload считает Pandas. Обзор без выбранного MPN ограничен 400 точками с наибольшим `stock_qty`.

### 6.4. Массовое наполнение каталога

**Просто.** Система сама листает каталоги поставщиков и складывает артикулы в базу, не открывая каждую карточку тяжёлым браузером.

**Технически.** `src/fast_scraper.py` (httpx): пагинация `?page=N` / `&start=`, warmup ChipDip, cp1251 для Платана, `accept_all_parts`, upsert в SQLite. Playwright остаётся для карточек и PDF.

### 6.5. Поиск аналогов своей линейки

**Просто.** Для «нашего» МК система предлагает близкие по ядру и корпусу позиции конкурентов и считает, где мы выгоднее или слабее по памяти и цене.

**Технически.** Pin-compatible фильтр (`core_arch`, `package`) → масштабирование признаков → KNN k=5. Дельты `(our − comp) / comp` по цене, Flash, RAM; порог 5%.

### 6.6. Отчёт с проверкой фактов

**Просто.** Нейросеть пишет выводы по-русски. Отдельный «контролёр» вычёркивает фразы, для которых нет цифры в таблице. Отчёт сначала черновик — человек подтверждает.

**Технически.** Агент 2 (`ReportDraft`) + `FactValidator`. LLM не вычисляет метрики. `llm_confidence < 0.8` → `needs_review`. Статус PDF: `draft` / `validated` / `archived`.

### 6.7. Публикация

**Просто.** Работает в интернете по адресу dp32.shastudio.ru, рядом с другими сервисами той же машины.

**Технически.** Контейнеры `mcu-analyzer` и `mcu-analyzer-web`, порт хоста `127.0.0.1:8082`, сеть `shastudio_default`, TLS через `shastudio-nginx`.

## 7. Преимущества

| Простыми словами | Технически |
|---|---|
| Нейросеть не может «округлить» цену от себя — процент считает таблица | Разделение: Pandas / scikit-learn для чисел, LLM только для текста и копирования полей |
| Не нужен дорогой сервер баз данных | SQLite WAL, однофайловый snapshot, бэкап копированием файла |
| Один артикул — сразу три магазина | Витрина читает последний срез `mcu_data`, а не три ручных Excel |
| Если сайт поставщика закрыл доступ, остальное не падает | 403/timeout: backoff, skip URL, пайплайн продолжает; ChipDip warmup |
| Повторный запуск не жжёт лишние запросы к нейросети | diskcache HTML→JSON, кэш HTML карточек |
| Секреты не светятся в GitHub | `.env` вне репозитория, ключи не хардкодятся |
| Можно проверить логику без живой нейросети и без интернета | pytest по экстрактору, матчеру, валидатору, вебу, fast_scraper, search:web (моки) |
| Человек остаётся в контуре решения | Human-in-the-Loop: отчёт `draft`, пока не просмотрен |
| Бюджетный тариф нейросети | Две модели по роли: 14B на извлечение, 32B на текст отчёта; лимиты `search:web` |
| Каталог масштабируется до тысяч строк, страница не «зависает» | Пагинация finder, потолок точек графика, httpx вместо Playwright на листингах |

## 8. Пайплайн: от сайта до PDF

Одна команда: `python src/pipeline.py`.

1. **Листинги.** httpx листает ЧипДип / Платан / Промэлектронику → цена и наличие в SQLite.  
2. **Поиск карточек.** `search:web` предлагает URL (или берутся цели из `scrape_targets.json`).  
3. **Карточки.** Playwright сохраняет HTML в `data/raw/`.  
4. **Извлечение.** Селекторы, при необходимости агент 1 → `MCUExtractSpec`.  
5. **Срез.** `load_latest_snapshot` — актуальная строка на пару «артикул + конкурент».  
6. **Аналоги.** Pin-compatible + KNN + дельты Pandas.  
7. **Отчёт.** Агент 2, валидатор фактов, Jinja2 → PDF.

Если конкурентов в срезе нет, система пишет «недостаточно данных» и **не додумывает** цифры.

| `/finder` | Фильтры и таблица уникальных МК, по 50 на страницу |

## 10. Надёжность, ограничения, итог

**Надёжность (просто).** Сайт конкурента может ответить «доступ запрещён» — система записывает это в журнал и идёт дальше. Повтор при сбое нейросети — до трёх раз.

**Надёжность (технически).** Retry LLM ≤ 3, backoff `2**retry` на 429/500, Playwright failure → skip, `Cache-Control: no-store` на демо, cron `0 3 * * *`.

**Ограничения MVP.** ЧипДип с части сетей даёт 403; Промэлектроника с VPS может показать капчу; полный обход всех страниц каталога занимает время; PDF на Windows без GTK идёт через Playwright.

**Итог.** Собрана законченная цепочка дипломного MVP: сбор рынка, честный расчёт, контролируемый текст нейросети, публичное демо. Код и инструкция запуска — в репозитории GitHub, живая витрина — https://dp32.shastudio.ru.
